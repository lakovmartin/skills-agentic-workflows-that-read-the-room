## Recent GitHub Blog highlights

- **Configure cost and quality in Copilot auto model selection** — "auto" mode now
  has three tiers (efficiency, balance, intelligence) so teams can tune cost vs.
  quality. (Source: GitHub Changelog, 2026-09-14)
- **Auto-resolution in Copilot code review** — Copilot code review now
  auto-resolves its own comments once addressed and writes smart commit
  messages when suggestions are applied. (Source: GitHub Changelog, 2026-09-11)
- **GitHub Copilot app for Beginners: diff, terminal, and browser** — a
  practical walkthrough of viewing diffs, running terminal commands, and
  previewing web apps side-by-side inside the Copilot app. (Source: GitHub
  Blog, 2026-09-10)
- **Refreshed repository pull requests page (public preview)** — a redesigned
  repo-level PR listing with richer filtering and a compact view mode.
  (Source: GitHub Changelog, 2026-09-10)
- **Control GitHub Actions cache access with `cache-mode`** — a new setting
  applies least-privilege access controls to the Actions cache at the
  workflow or job level. (Source: GitHub Changelog, 2026-09-10)

## Awesome GitHub Copilot: community resources worth exploring

The [Awesome GitHub Copilot](https://awesome-copilot.github.com/) site
catalogs community-contributed agents, instructions, and skills for
extending Copilot. Useful entry points for readers:

- **Agents** — custom agents for specialized Copilot experiences.
- **Instructions** — coding standards and best practices for Copilot.
- **Skills** — self-contained folders bundling instructions and resources
  (e.g. a [spec-driven workflow](https://awesome-copilot.github.com/instruction/spec-driven-workflow-v1/)
  or [GitHub Action workflow specification skill](https://awesome-copilot.github.com/skill/create-github-action-workflow-specification/)).
- **Plugins** — curated plugins organized by theme, including agentic
  workflow plugins for modernization tasks.
- **Learning Hub** — includes a guide on
  [agentic workflows](https://awesome-copilot.github.com/learning-hub/agentic-workflows/)
  for readers new to the concept.

_Note: the site does not currently have a dedicated "/workflows/" section;
the closest matches are the Agents, Skills, Plugins, and Learning Hub
categories above._
