## Recent updates worth watching

- **GitHub Copilot coding agent**: Copilot can now be assigned GitHub issues directly and will open a draft pull request with proposed changes for review, similar to delegating work to a teammate. (Source: GitHub Blog, github.blog/changelog)
- **GitHub Copilot CLI**: An agentic command-line interface lets developers ask Copilot to plan and execute multi-step terminal tasks (searching code, running tests, editing files) with explicit approval steps. (Source: GitHub Blog)
- **Custom instructions & agents.md**: Repositories can define custom instructions files so Copilot follows project-specific conventions automatically across chat, PR reviews, and coding agent sessions. (Source: GitHub Changelog)
- **GitHub Actions immutable releases & artifact attestations**: Actions now supports build provenance attestations, making it easier to verify that release artifacts were built by a trusted workflow. (Source: GitHub Changelog)
- **Pull request merge queue improvements**: Merge queues continue to gain refinements for required status checks and branch protection, reducing merge conflicts in high-traffic repos. (Source: GitHub Changelog)
