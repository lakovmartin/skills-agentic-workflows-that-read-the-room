## Quick tips for readers

- **Copilot coding agent**: Assign an issue directly to Copilot and it opens a
  draft pull request with proposed changes for you to review — a fast way to
  offload well-scoped bug fixes and small features. (Source: GitHub Blog,
  github.blog/latest)
- **Copilot code review**: Request an automated review on a pull request to
  get inline suggestions before asking a human teammate — useful as a first
  pass on style and obvious issues. (Source: GitHub Blog, github.blog/latest)
- **Custom instructions for Copilot**: Add a `.github/copilot-instructions.md`
  file to steer Copilot's suggestions and chat responses toward your repo's
  conventions. (Source: GitHub Changelog, github.blog/changelog)
- **Actions workflow visualization & reusable workflows**: Use reusable
  workflows (`workflow_call`) to share CI/CD logic across repositories instead
  of duplicating YAML. (Source: GitHub Changelog, github.blog/changelog)
