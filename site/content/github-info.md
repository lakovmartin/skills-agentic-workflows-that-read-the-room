# GitHub Info

## Mona's editorial angle

## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.
- GitHub Actions as the automation layer behind repository workflows.
- Recent GitHub Blog and Changelog stories worth watching.

## Explore ready-made Copilot workflows

- **Awesome Copilot Workflows** (awesome-copilot.github.com/workflows) is a
  community-curated catalog of reusable [GitHub Agentic Workflows](https://github.com/githubnext/gh-aw)
  you can drop into a repo — things like automated issue triage, PR review
  assistants, and scheduled research digests, all defined as versioned
  markdown + YAML workflow files.
- For developers learning GitHub automation, browsing this catalog is a fast
  way to see practical `gh aw` workflow patterns before writing one from
  scratch.
  _Source: awesome-copilot.github.com/workflows_

## Staying current with GitHub

- The **GitHub Blog** (github.blog/latest) covers product announcements,
  engineering deep-dives, and Copilot feature stories — check it periodically
  for context behind new capabilities.
- The **GitHub Changelog** (github.blog/changelog) is the fastest way to see
  exactly what shipped this week: new Actions features, Copilot model and IDE
  updates, security and administration changes, and API updates.
- Because both feeds update frequently, treat any specific dated post as a
  snapshot — link back to the original Blog or Changelog entry when citing a
  feature so readers can verify the latest details themselves.
