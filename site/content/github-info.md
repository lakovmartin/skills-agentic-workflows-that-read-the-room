## Recent GitHub Changelog highlights

- **Copilot code review can now approve pull requests** — Copilot's automated
  review can mark a PR as approved when it finds no blocking issues, speeding
  up low-risk merges.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-01-copilot-code-review-can-now-approve-pull-requests))
- **GPT-6 Astra is generally available in GitHub Copilot** — a new model
  option is rolling out across Copilot surfaces for developers who want the
  latest reasoning improvements.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-04-gpt-6-astra-is-generally-available-in-github-copilot))
- **Content exclusions are generally available in the Copilot app and CLI** —
  teams can now keep specific files and paths out of Copilot's context across
  more surfaces, not just the IDE.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-02-content-exclusions-generally-available-in-copilot-app-and-cli))
- **GitHub Actions: Early September 2026 updates** — a roundup of workflow
  and runner improvements worth a quick skim if you rely on Actions daily.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-03-github-actions-early-september-2026-updates))
